# CBCSC demo content

## Option 1 — recommended

Activate **Baloch Heritage Canada**, then go to **Baloch Heritage → Tools** and select **Import Data** (or **Repair Demo Data**). This automatically creates the pages, homepage setting, menu, events, leaders, and resources used by the theme.

## Option 2 — standard WordPress import

1. Activate the Baloch Heritage Canada theme first. This registers the theme's custom content types.
2. In WordPress, go to **Tools → Import → WordPress**. Install the WordPress Importer if prompted.
3. Upload `cbcsc-demo-content.xml`.
4. Assign the imported author to your administrator account. Do not download attachments: this demo does not include stock or third-party images.
5. Go to **Settings → Reading** and set **Home** as the static homepage.
6. Go to **Appearance → Menus → Manage Locations** and assign your Primary Navigation menu.

The imported event and resource entries are clearly marked sample content. Replace their details and add approved images before publishing.
